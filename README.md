# 📚 Library Book Record Application

## 📌 Project Description

The Library Book Record Application is a JavaFX desktop application developed to manage library book records.

The application allows the user to add, update, delete, search, issue, and return books. Book records are saved in a text file so that the data remains available when the application is opened again.

## ✨ Features

- Add new books
- Update book information
- Delete books
- Search books by ID or title
- Display all books
- Issue books
- Return books
- Select book records from the table
- Show Available and Issued status
- Automatically save book records
- Simple and user-friendly JavaFX interface
- Resizable application window

## 🛠️ Technologies Used

- Java
- JavaFX
- Eclipse IDE
- Git
- GitHub
- GitHub Actions
- Text File Storage
